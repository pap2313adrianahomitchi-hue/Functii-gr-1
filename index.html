📈 Funcția de gradul I

Teorie, grafic interactiv și exerciții pentru examenul de clasa a 9-a (R. Moldova)

1. Definiție

Funcția f : ℝ → ℝ, f(x) = ax + b, cu a ≠ 0, se numește funcție de gradul I. Graficul ei este o dreaptă.
  • a – panta (coeficientul lui x)
  • b – termenul liber (ordonata la origine)

2. Valoarea funcției într-un punct

Înlocuim x cu numărul dat.
f(x) = 2x − 3 ⇒ f(4) = 2·4 − 3 = 5

3. Intersecția cu axele

  • Cu Oy: x = 0 ⇒ punctul (0; b)
  • Cu Ox (zeroul funcției): f(x) = 0 ⇒ x = −b/a, punctul (−b/a; 0)
f(x) = 2x − 6: 2x − 6 = 0 ⇒ x = 3, deci A(3; 0) și B(0; −6)

4. Monotonia

  • a > 0 ⇒ f strict crescătoare (dreapta „urcă”)
  • a < 0 ⇒ f strict descrescătoare (dreapta „coboară”)
Semnul funcției: pentru a > 0, f(x) > 0 când x > −b/a; pentru a < 0, f(x) > 0 când x < −b/a.

5. Apartenența unui punct la grafic

Punctul M(p; q) aparține graficului lui f dacă f(p) = q.
f(x) = 3x − 1, M(2; 5): f(2) = 5 ✔ M ∈ Gf

6. Dreapta prin două puncte

Pentru A(x₁; y₁), B(x₂; y₂):
a = (y₂ − y₁)/(x₂ − x₁), apoi b = y₁ − a·x₁

7. Poziția a două drepte

f(x) = a₁x + b₁, g(x) = a₂x + b₂
  • Paralele: a₁ = a₂ și b₁ ≠ b₂
  • Coincid: a₁ = a₂ și b₁ = b₂
  • Secante: a₁ ≠ a₂; punctul de intersecție se află din f(x) = g(x)

8. Aria triunghiului format cu axele

Dreapta taie axele în A(−b/a; 0) și B(0; b); triunghiul OAB are aria
𝒜 = ½ · |b| · |−b/a| = b² / (2|a|)
